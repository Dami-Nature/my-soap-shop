## Что делаем

1. На странице товара (`product.html`) — карусель из нескольких фото вместо одного изображения.
2. В данных товара (`products.js`) — добавляем поле `images: []` для дополнительных фото.
3. Новый файл `config.js` — хранит настройки главной страницы (фото баннера, блок «О себе», карточки каталога).
4. Обновляем `index.html` — загружает `config.js` и рендерит динамически.
5. В админке (`admin.html`) — два таба «Товары» / «Сайт», мульти-фото в редакторе товара.

---

## 1. Модель данных

### products.js — добавляем `images`

Каждый товар получает необязательное поле `images`:

```js
{
  id: 1,
  name: 'Лесное с пихтой',
  image: 'images/soap-forest.jpg',   // главное фото (в каталоге, первое в карусели)
  images: [                           // НОВОЕ: дополнительные фото карусели
    'images/soap-forest-2.jpg',
    'images/soap-forest-3.jpg'
  ],
  // ... остальные поля без изменений
}
```

**Обратная совместимость:** если `images` отсутствует или пустой — показывается только `image`. Старые данные не ломаются.

### config.js — новый файл

```js
const CONFIG = {
  hero: {
    image: 'images/hero.jpg'
  },
  about: {
    image: 'images/about.jpg',
    text: 'Приветствую Вас!...'
  },
  categoryCards: {
    cosmetics: 'images/cosmetics-card.jpg',
    teas: 'images/teas-card.jpg',
    sets: null   // null = показывать иконку ❦ (как сейчас), заменяется когда загрузят фото
  }
};
```

## 2. Страница товара (`product.html`)

**Карусель** заменяет единственное фото слева:

- Собирает массив фото: `[p.image, ...(p.images || [])]` (пропуская null)
- Если фото одно — карусель без стрелок/точек (как раньше)
- Если несколько:
  - Стрелки «‹» / «›» по бокам (кликабельные)
  - Точки-индикаторы снизу
  - Свайп пальцем на мобильном (touchstart / touchend)
  - Авто-высота: `aspect-ratio: 1`, `object-fit: cover`
- При ошибке загрузки фото — эмодзи-заглушка (как сейчас)

---

## 3. Главная страница (`index.html`)

Добавляется `<script src="config.js"></script>` перед `app.js`.

Три секции становятся динамическими:
- **Hero:** `<img>` баннера берёт `src` из `CONFIG.hero.image`
- **Карточки каталога:** фото из `CONFIG.categoryCards.cosmetics` / `.teas` / `.sets`
- **«О себе»:** фото из `CONFIG.about.image`, текст из `CONFIG.about.text` (поддерживает `\n` → `<br>`)

Всё остальное (заголовки, кнопки, цвета) остаётся в HTML.

## 4. Админка (`admin.html`)

### Два таба

В шапке — переключатель «Товары» / «Сайт». Сохраняет текущий таб в памяти (не localStorage).

### Таб «Товары» — изменения в редакторе

Блок фото заменяется **полосой миниатюр**:

```
[ фото1 × ] [ фото2 × ] [ + добавить ]
```

- Первое фото = `image` (главное, показывается в каталоге)
- Остальные = `images[]` (только в карусели товара)
- Крестик удаляет фото из списка
- `+` открывает `<input type="file">`, добавляет фото в конец
- При сохранении товара: первый элемент → `image`, остальные → `images`
- Новые файлы буферизуются в `newImages{}` (как сейчас), публикуются вместе с остальными

### Таб «Сайт»

Список элементов с разделами:

**🏠 Главная страница**
- «Фото баннера» → sheet с zone загрузки фото (меняет `config.hero.image`)

**👤 Блок «О себе»**
- «Фото Эмилии» → sheet с zone загрузки (меняет `config.about.image`)
- «Текст биографии» → sheet с `<textarea>` (меняет `config.about.text`)

**🗂 Карточки каталога**
- «Косметика — фото» → sheet с zone загрузки
- «Чаи — фото» → sheet с zone загрузки
- «Наборы — фото» → sheet с zone загрузки

Каждый пункт открывает bottom-sheet в том же стиле что и редактор товара.

### Публикация

Кнопка «Опубликовать» работает для обоих табов:
1. Загружает новые изображения в GitHub
2. Коммитит обновлённый `products.js`
3. Коммитит обновлённый `config.js`

## 6. Что не меняется

- `cosmetics.html`, `teas.html`, `sets.html` — без изменений
- `app.js`, `nav.js`, `style.css` — без изменений
- Логика публикации через GitHub API — та же
- Механизм кеш-бастинга — распространяется и на `config.js`
